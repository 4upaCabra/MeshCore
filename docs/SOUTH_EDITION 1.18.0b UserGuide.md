# Руководство пользователя south_edition (v1.18.0b1)

Как пользоваться прошивкой south_edition: экран и кнопки компаньона, все пункты настроек, подключение
приложения, командная строка, репитер и комнатный сервер, питание.

Как прошить плату — в отдельном руководстве: [Прошивка south_edition](flashing.md).

> Руководство обновляется вместе с прошивкой. Актуально для v1.18.0b1 и следующих сборок ветки
> `south_edition`; где поведение выпуска v1.18.0b1 отличается, это оговорено.

## 1. Что это за прошивка

south_edition — сборка на основе [MeshCore](https://github.com/meshcore-dev/MeshCore) 1.18 с
доработками для полевой работы:

- **одна прошивка компаньона** с Bluetooth, USB и (на ESP32) WiFi — канал связи с приложением
  переключается на ходу;
- **русский интерфейс** на экране и транслитерация кириллицы;
- **командная строка (CLI) на компаньоне** — из приложения, по отдельному каналу и удалённо по PIN;
- **настраиваемая защита от разряда батареи** для всех ролей;
- **энергосбережение ESP32** и асинхронное обновление e-ink.

Совместима с официальными приложениями MeshCore и с узлами на обычной прошивке MeshCore.

## 2. Компаньон: экран и кнопки

### 2.1. Управление

Узел управляется одной кнопкой:

| Действие | Как сделать |
|---|---|
| следующая страница / пункт | короткое нажатие |
| предыдущая страница / назад | двойное нажатие |
| войти, выполнить, изменить значение | долгое нажатие (удержание) |
| вкл/выкл звук (если есть зуммер) | тройное нажатие |

Любое нажатие при погасшем экране только включает экран.

### 2.2. Страницы главного экрана

Страницы листаются по кругу. Набор зависит от платы: например, страница GPS есть только у плат с GPS.

| Страница | Что показывает | Действие (удержание) |
|---|---|---|
| **Часы** | время, дату, источник времени. При непрочитанных личных сообщениях — само сообщение во весь экран | листание непрочитанных сообщений |
| **Сообщения** | число новых или всех сообщений, состояние связи (`< Подключено >`, IP при WiFi), PIN Bluetooth | открыть новые сообщения или историю |
| **Недавние** | узлы, которые были слышны недавно, и сколько времени назад | — |
| **Радио** | частота, SF, BW, CR, мощность, уровень шума | — |
| **Bluetooth** | значок вкл/выкл (только в сборках без выбора канала связи) | включить / выключить Bluetooth |
| **Маяк** | значок маяка | отправить маяк (advert) в сеть |
| **GPS** | состояние GPS, фикс, спутники, координаты, высота | включить / выключить GPS |
| **Поиск ретрансляторов** | ретрансляторы в прямой видимости и качество связи с ними (SNR туда / обратно) | запустить поиск (не чаще раза в 5 с) |
| **Настройки** | вход в настройки и версия прошивки | войти в настройки |
| **Выключение** | только на платах с режимом гибернации | выключить узел |

### 2.3. Сообщения

- Новое личное сообщение всплывает на экране. Сколько оно держится, если его уже забрало приложение,
  задаёт «Время показа» (раздел 3.1).
- Из всплывающего сообщения: «следующая» — к следующему непрочитанному, «назад» — на главный экран.
- В истории сообщения листаются вперёд и назад; выход — удержанием.

## 3. Настройки

Вход: страница «Настройки» → удержание. Внутри — папки. Пункт `< Назад` в каждой папке
возвращает на уровень выше, `[ Выход ]` — из настроек. Значение пункта меняется удержанием.
Изменения сохраняются сразу.

### 3.1. Сообщения

| Пункт | Значения | Что делает |
|---|---|---|
| Уведомл. | Только ЛС / Все | какие входящие показывать всплывающим окном |
| Время показа | Выкл / 5 / 15 / 30 с | сколько держать сообщение на экране, если его уже забрало приложение (по умолчанию 5 с) |
| Транслит | Выкл / Канал / ЛС / Все | переводить кириллицу в латиницу в названиях каналов и/или контактов |
| Чат в порт | Все / Канал / ЛС / Выкл | откуда принимаются команды CLI: **Все** — канал TerminalCLI и личные сообщения; **Канал** — только канал TerminalCLI; **ЛС** — только удалённо личными сообщениями; **Выкл** — ниоткуда |
| История | 16 / 32 / 64 | сколько сообщений хранить |

### 3.2. Экран

| Пункт | Значения | Что делает |
|---|---|---|
| Язык | EN / RU | язык интерфейса |
| Часы всегда | Выкл / Всегда | не гасить экран на странице часов (только на платах с автоотключением экрана) |
| Поворот | 0° / 90° / 180° / 270° | ориентация экрана (только e-ink) |

### 3.3. Связь

| Пункт | Значения | Что делает |
|---|---|---|
| Интерфейс | BLE / USB / WiFi | канал связи с приложением (раздел 4). Без WiFi переключает BLE ↔ USB; на ESP32 открывает список сетей WiFi |
| PIN админа | `****` | PIN удалённого CLI (раздел 5.3): нажатие показывает его на 3 секунды, повторное нажатие, пока PIN виден, создаёт новый |
| Префикс BLE | Вкл / Выкл | добавлять `MeshCore-` к имени узла в Bluetooth (применяется после перезагрузки) |
| Синхр. врем. | Все / GPS / Mesh | откуда брать время: **Все** — маяки и сообщения сети; **GPS** — только GPS и приложение; **Mesh** — только маяки сети |

### 3.4. Система

| Пункт | Значения | Что делает |
|---|---|---|
| Энергосбер. | Авто / Выкл / Мягкий / Макс | режим сна ESP32 (раздел 7.2); на nRF52 пункта нет. В v1.18.0b1 «Мягкий» назывался «Эконом» |
| Калибр. АКБ | текущее напряжение | калибровка измерения батареи: подключите USB и подтвердите — узел подстроит множитель |
| Откл. по АКБ | Выкл / 3,0 / 3,2 / 3,4 В | порог защиты от разряда (раздел 7.1) |
| Кодеки > | — | папка декодеров |

**Кодеки** — что делать с сообщениями в канале, которые отправлены не обычным текстом, а в формате
сторонних клиентов. Каждый пункт включается отдельно.

| Пункт | Что делает узел |
|---|---|
| MCOtxt | **расшифровывает** сжатый текст: на экране и в приложении видно само сообщение |
| MCMP | только **распознаёт**: вместо содержимого пишет заглушку `<MCMP v… message>` |
| AEIC | только распознаёт картинку: `<AEIC image>` (один раз на картинку, а не на каждый её кусок) |
| MCOimg | только распознаёт картинку: `<MCOimg v… image>` |

Содержимое MCMP, AEIC и MCOimg узел не раскрывает — заглушка лишь сообщает, от кого и что пришло.
Приложение, которое само понимает формат, получает исходное сообщение без изменений; заглушку или
расшифрованный текст получает только приложение, которое этот формат не поддерживает.

## 4. Подключение приложения

### 4.1. Bluetooth

- **Плата с экраном** — при каждом включении новый случайный PIN; он показан на странице «Сообщения»
  (`Pin:…`).
- **Плата без экрана** — постоянный PIN `123456`.
- Свой постоянный PIN: `set ble.pin <6 цифр>`; `set ble.pin 0` — вернуть поведение по умолчанию.
  Применяется после перезагрузки.
- Если телефон перестал подключаться после перепрошивки — удалите узел в Bluetooth телефона
  («Забыть устройство») и выполните сопряжение заново.

### 4.2. USB

Настройки → Связь → Интерфейс → **USB** (или `set comms usb`). Bluetooth при этом выключается.
Подключите приложение кабелем к порту платы. Вернуться на Bluetooth — тем же пунктом или
`set comms ble`.

### 4.3. WiFi (только ESP32)

1. Сохраните сеть: `wifi add <имя сети> <пароль>` (имя с пробелами — в кавычках).
2. Настройки → Связь → Интерфейс → выберите сеть (или `set comms wifi`).
3. IP-адрес появится на странице «Сообщения»; приложение подключается к нему по TCP, порт 5000
   (`wifi port <номер>` — сменить).

Полезное: `wifi list` (сохранённые сети), `wifi status`, `wifi del <имя>`,
`wifi ip static <ip> <шлюз> <маска>` / `wifi ip dhcp`. В режиме WiFi Bluetooth тоже работает.

## 5. Командная строка компаньона (CLI)

### 5.1. Где вводить команды

- **В приложении** — раздел командной строки (CLI) узла.
- **Канал TerminalCLI** — отправьте команду сообщением в этот канал (`set terminal.cli on` — создать
  канал).
- **По USB, режим CLI Rescue** — удержите кнопку в первые 8 секунд после включения и откройте порт
  терминалом на 115200. Повторное удержание — выход. В режиме связи USB недоступен.
- **Удалённо по PIN** — раздел 5.3.

`help` — список разделов справки; `help radio`, `help sys`, `help app`, `help all`.

### 5.2. Основные команды

| Команда | Что делает |
|---|---|
| `ver`, `board` | версия прошивки и модель платы |
| `pin` | PIN удалённого CLI и PIN Bluetooth |
| `get radio`, `set radio …` | параметры радио: частота, BW, SF, CR, мощность (`help radio` — синтаксис) |
| `get name` / `set name <имя>` | имя узла |
| `clock`, `time` | состояние часов узла |
| `timesync` | синхронизация времени: `on`/`off`, `adverts on/off`, `msgs on/off`, `params`, `reset` |
| `neighbors` | слышимые узлы |
| `stats-core`, `stats-radio`, `stats-packets` | статистика |
| `reboot`, `poweroff` | перезагрузка, выключение |
| `get/set cyr2lat.channels`, `cyr2lat.contacts` | транслитерация |
| `get/set mcotxt`, `mcmp.detect`, `aeic.detect`, `mcoimg.detect` | декодеры форматов |
| `get/set comms ble\|usb\|wifi` | канал связи с приложением |

### 5.3. Удалённый CLI по PIN

Командами можно управлять узлом с любого другого узла сети, зная его PIN.

```
get cli.pin                 # PIN этого узла (8 шестнадцатеричных знаков)
set cli.pin new             # сгенерировать новый PIN
set remote.cli pin          # кому можно: pin | flag | both | off
set remote.cli.fav on       # отправитель с верным PIN становится избранным (по умолчанию on)
```

- **pin** — нужен верный PIN; **flag** — отправитель отмечен в контактах как администратор;
  **both** — любое из двух; **off** — удалённый CLI выключен.
- Команда с PIN: `<PIN> <команда>`, например `1a2b3c4d get radio`. Её можно отправить личным
  сообщением или с экрана командной строки (CLI) этого контакта в приложении.
- С экрана CLI верный PIN открывает **сеанс на 10 минут**: следующие команды можно слать без PIN;
  `logout` — завершить сеанс. В личных сообщениях PIN нужен в каждой команде — иначе любое сообщение
  в чате стало бы командой.
- Номер вида `01|` перед командой повторяется в ответе (`01|…`) — так приложение сопоставляет ответы.
- После 5 неверных PIN подряд отправитель игнорируется 10 минут.

## 6. Репитер и комнатный сервер

### 6.1. Первая настройка

Подключите узел по USB и откройте порт терминалом (115200) или веб-конфигуратор MeshCore. Минимум:

```
set name <имя узла>
set radio <частота> <bw> <sf> <cr>    # параметры вашего региона
password <новый пароль>               # пароль администратора
reboot
```

Дальше узлом можно управлять по радио из приложения (вход с паролем администратора).

### 6.2. Полезные команды

| Команда | Что делает |
|---|---|
| `help`, `help all` | команды роли; общий список команд |
| `advert`, `advert.zerohop` | отправить маяк в сеть / только соседям |
| `set advert.interval <мин>`, `set flood.advert.interval <ч>` | автоматические маяки |
| `get/set repeat on\|off` | пересылка пакетов (только репитер) |
| `get/set flood.max <0–64>` | предел числа переходов |
| `get/set loop.detect off\|minimal\|moderate\|strict` | защита от петель маршрутизации |
| `neighbors`, `discover.neighbors` | соседи; поиск ретрансляторов рядом |
| `setperm <ключ> <права>`, `get acl` | права клиентов (`get acl` — только по USB) |
| `set lat <…>`, `set lon <…>` | координаты узла |
| `room.post <текст>` | объявление в комнату: запись с автором «сам сервер» получат все участники (только администратор) |
| `stats-core`, `stats-radio`, `stats-packets`, `clear stats` | статистика |

## 7. Питание

### 7.1. Защита от разряда батареи

Одна настройка — порог в милливольтах — служит и блокировкой загрузки, и выключением во время работы.
По умолчанию **выключена**: прошивка не знает, какой у узла аккумулятор.

```
set pwrmgt.shutdown 3300    # порог, мВ; 0 или off — выключено
get pwrmgt.shutdown
get pwrmgt.bootmv           # напряжение при последней загрузке
get pwrmgt.bootreason       # причина последней перезагрузки или выключения
```

На компаньоне с экраном: Настройки → Система → «Откл. по АКБ».

| Аккумулятор | Ориентир порога |
|---|---|
| Li-ion / LiPo | 3000–3300 мВ |
| LiFePO4 | 2800–2900 мВ |
| LTO | 1900–2000 мВ |
| Натрий-ион | около 2000 мВ |

Как работает:

- ниже порога узел при включении не загружается, а сразу уходит в глубокий сон;
- во время работы напряжение проверяется раз в 10 секунд; 6 замеров подряд ниже порога (около минуты) —
  и узел засыпает. Короткая просадка при передаче не считается;
- после такого выключения для загрузки нужно порог плюс 150 мВ — узел не «моргает» у порога;
- **nRF52** просыпается сам при напряжении около 3,9 В или при подключении USB. LiFePO4, LTO и
  натрий-ион до 3,9 В не заряжаются — такие узлы включаются от USB или кнопкой сброса;
- **ESP32** просыпается по таймеру раз в 30 минут и проверяет батарею снова.

Если питание идёт через модуль заряда, который сам отключает нагрузку (например на 3,4 В), ставьте
порог немного выше — узел уснёт аккуратно, раньше модуля.

### 7.2. Энергосбережение ESP32

Настройки → Система → «Энергосбер.» или `set power.mode <режим>`:

| В меню | Команда | Поведение |
|---|---|---|
| Авто | `auto` | спит между событиями (по умолчанию) |
| Выкл | `off` | без сна: максимальная отзывчивость и наибольший расход |
| Мягкий (в v1.18.0b1 — «Эконом») | `conservative` | спит, только пока приложение не подключено |
| Макс | `aggressive` | как «Авто», но просыпается реже: экономнее, отклик чуть медленнее |

Плата не спит ни в каком режиме, пока выбран канал связи WiFi или USB, пока к USB подключён компьютер и
первые 30 секунд после включения. Если подключение по Bluetooth стало
медленным, для проверки поставьте «Выкл».

### 7.3. Калибровка батареи

Делитель напряжения на платах неточный, поэтому узел может показывать заряд с ошибкой в несколько
процентов. Калибровка по полной батарее исправляет это без мультиметра.

Принцип: полностью заряженный Li-ion аккумулятор на зарядке держит **4,20 В**. Узел измеряет
напряжение и подбирает поправочный множитель так, чтобы показание стало 4,20 В.

1. Поставьте узел на зарядку и дождитесь **окончания заряда** (индикатор зарядки погас или сменил
   цвет). USB **не отключайте**.
2. Сразу откройте Настройки → Система → «Калибр. АКБ». В строке пункта видно текущее показание.
3. На экране калибровки:
   - `4.12V>4.20V` — что узел измерил и к какому значению приведёт;
   - `k 1.000>1.019` — старый и новый множитель;
   - предупреждение, если оно есть (ниже);
   - внизу действие: `< Отмена >`, `< Применить >` или `< Сброс >`. Короткое нажатие меняет действие,
     удержание выполняет, двойное — выход без изменений.
4. Выберите «Применить». Узел измерит ещё раз; если показание не сошлось с 4,20 В в пределах 3 %,
   множитель не сохранится.

| Предупреждение | Что значит |
|---|---|
| Нет питания USB | узел не на зарядке (только nRF52): батарея уже отстоялась, результат будет занижен |
| Нестабильно | показания скачут больше чем на 80 мВ: батареи нет или зарядник работает импульсами |
| Вне диапазона | нужна поправка больше 15 %: батарея не заряжена полностью или неисправна — «Применить» недоступно |
| Нет данных | плата не измеряет батарею |

«Сброс» возвращает заводской множитель. Пункта нет на платах, где множитель не настраивается.

Это грубая калибровка: после окончания заряда напряжение за несколько минут опускается к ~4,1 В, и
ошибка доходит до 2 %. Точнее — с мультиметром: измерьте напряжение на батарее и подберите множитель
командами `get adc.multiplier` / `set adc.multiplier <число>` (`0` — заводское значение).

## 8. Частые вопросы

| Вопрос | Ответ |
|---|---|
| Узел не загружается от батареи | задан порог отключения выше её напряжения: подключите USB и `set pwrmgt.shutdown 0` или нужный порог |
| Телефон долго подключается | «Забыть устройство» и сопряжение заново; на ESP32 — проверить с «Энергосбер.» → Выкл |
| Как узнать версию | страница «Настройки» или команда `ver` |
| Не вижу пункта меню | часть пунктов есть только на платах с нужным оборудованием (GPS, e-ink, ESP32, измерение батареи) |
| Перестали приходить команды CLI | проверьте «Чат в порт» (раздел 3.1) и `get remote.cli` |
| Компаньон сам выключается | сработал порог «Откл. по АКБ» — зарядите батарею или измените порог |
